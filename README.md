# 🎬 MovieMan — HTML & CSS Project

**Streamly** is a front-end movie website, built entirely with **HTML** and **CSS** as the first project in a 7-part Full-Stack Development course.

## 🌟 Overview
Streamly presents a clean, modern movie browsing experience where users can explore different movie genres through an intuitive layout and simple navigation.  
This project focuses purely on the **structure** and **styling** layers of web development — without JavaScript — to demonstrate mastery of semantic HTML, responsive CSS, and visual design fundamentals.

## 🧩 Features
- **Homepage** — personalized greeting and introduction.  
- **Navigation bar** — genre links (Action, Drama, Romance, New & Popular).  
- **Category pages** — display movies in Netflix-style layout using Flexbox and Grid.  
- **Movie cards** — include poster images with rounded corners and hover effects.  
- **Trailer embeds** — YouTube videos integrated via `<iframe>` (with autoplay and mute).  
- **Fully responsive** design adapting to different screen sizes.

## 🛠️ Technologies
- **HTML5** for semantic structure  
- **CSS3** for layout, colors, and styling  
- **Flexbox** & **CSS Grid** for responsive movie grids
